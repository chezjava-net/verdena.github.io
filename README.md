# VERDENA

**Plants for a Better Tomorrow.**

A complete static plant-and-home-greenery storefront with **12 demo products**, categories, room shopping, plant guides, wishlist, shopping bag, support, responsive layouts, and local product photography.

## Image standard

Each product card uses a dedicated local image asset with one primary product per image. Product photos are placed inside square frames using `object-fit: contain`, centered with natural proportions, without prices, buttons, ratings, navigation, or website screenshots embedded in the photography.
